로컬 요청에서는 예시의 `https://blog.example`을 `http://localhost:8080`으로 바꿉니다. 운영 주소는 `https://blog.homelab.robinjoon.xyz`이며 예시 UUID는 테스트 데이터입니다.

== 공개 상태와 응답

* 글은 관리자가 발행해 공개 상태이고 읽을 수 있는 공개본이 있을 때만 제공합니다. Notion의 공개 설정·휴지통·이동은 공개 여부를 바꾸지 않습니다.
* 웹 요청은 저장된 내용만 사용합니다. Notion 장애가 공개 글을 곧바로 숨기지 않습니다.
* 사이트 설정이나 표현 자산을 사용할 수 없으면 형식이 올바른 게시글 ID에도 먼저 `503`을 반환할 수 있습니다.
* HTML 전체 마크업과 표현 자산은 화면 구현에 따라 바뀔 수 있습니다.

[options="header,autowidth"]
|===
|상태 |의미
|`200 OK` |HTML, RSS 또는 파일을 제공합니다.
|`303 See Other` |관리 명령 뒤 미리보기나 목록으로 돌아갑니다.
|`400 Bad Request` |관리 명령의 식별자 형식이 잘못되었습니다.
|`404 Not Found` |대상이 없거나 공개 상태가 아닙니다. 형식이 잘못된 ID도 포함합니다.
|`503 Service Unavailable` |필요한 저장본·설정을 사용할 수 없습니다.
|===

== 글 목록

`GET /`는 관리자 홈 설정에 따른 공개 글 목록을 반환합니다. `page`로 쪽을 선택하고 `category`에 카테고리 UUID를 보내 필터링합니다. 잘못되었거나 없는 카테고리는 `404`입니다. 쪽 크기·정렬·표시 항목은 관리자 설정을 따르며 공개 요청으로 바꾸지 않습니다.

== RSS 피드

* `GET /feed.xml`은 RSS 2.0 XML을 반환합니다. 공개된 글 중 사이트 문서(루트·헤더·푸터)를 제외한 최근 20개를 요약과 함께 제공합니다.
* `pubDate`는 처음 발행한 시각이며 수정·발행 취소·재발행으로 바뀌지 않습니다.
* 절대 URL은 `blog.public-base-url` 설정에서 만듭니다. 공개할 글이 없어도 준비된 블로그는 빈 피드를 `200`으로 반환합니다.

== 공개 파일

* `GET /media/{mediaKey}`는 공개본이 참조하는 보관 파일만 제공합니다. 발행을 취소하면 곧바로 `404`입니다.

== 관리 경로

* `/admin/**`은 `BLOG_ADMIN_USERNAME`·`BLOG_ADMIN_PASSWORD`로 설정한 단일 운영자만 쓰며, 둘 중 하나라도 비어 있으면 로그인 화면을 포함해 `403`으로 닫힙니다. 로그인되지 않은 요청은 `/admin/login`으로 이동합니다. 로그인 제출(`POST /admin/login`)과 로그아웃(`POST /admin/logout`)은 보안 필터가 처리하며 이 문서의 예시에 없습니다. 로그인 성공은 `/admin/posts`로 이동하고, 실패는 이유를 구분하지 않고 `/admin/login?error`로 이동합니다. 모든 `POST`는 로그인·로그아웃을 포함해 CSRF 토큰이 필요합니다. 아래 예시는 인증을 통과한 요청에 컨트롤러가 답하는 내용이며 보안 필터는 포함하지 않습니다.
* 관리 응답은 `Cache-Control: no-store`입니다.
* 발행은 미리보기가 준 `revisionId`와 `generation`을 함께 보냅니다. 그 사이 새 변경이 생기면 발행하지 않고 미리보기로 돌아가 안내합니다. 발행 취소·보관·복원은 Notion 없이 처리합니다.
