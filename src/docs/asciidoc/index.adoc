로컬 요청에서는 예시의 `https://blog.example`을 `http://localhost:8080`으로 바꿉니다. 운영 주소는 `https://blog.homelab.robinjoon.xyz`이며 예시 UUID는 테스트 데이터입니다.

== 공개 상태와 응답

* 글은 관리자가 발행해 공개 상태이고 읽을 수 있는 공개본이 있을 때만 제공합니다. Notion의 공개 설정·휴지통·이동은 공개 여부를 바꾸지 않습니다.
* 웹 요청은 저장된 내용만 사용합니다. Notion 장애가 공개 글을 곧바로 숨기지 않습니다.
* 사이트 설정이나 표현 자산을 사용할 수 없으면 형식이 올바른 게시글 ID에도 먼저 `503`을 반환할 수 있습니다.
* HTML 전체 마크업과 표현 자산은 화면 구현에 따라 바뀔 수 있습니다.

[options="header,autowidth"]
|===
|상태 |의미
|`200 OK` |HTML, RSS 또는 파일을 제공합니다.
|`303 See Other` |관리 명령 뒤 상세·발행 확인·목록으로 돌아갑니다.
|`400 Bad Request` |관리 명령의 식별자 형식이 잘못되었거나 검색어가 너무 깁니다.
|`404 Not Found` |대상이 없거나 공개 상태가 아닙니다. 형식이 잘못된 ID도 포함합니다.
|`503 Service Unavailable` |필요한 저장본·설정을 사용할 수 없습니다.
|===

== 글 목록

`GET /`는 관리자 설정에 따른 공개 글 목록을 반환합니다. 응답에는 글·시리즈 탭, 태그 탐색(설정에서 켠 경우), 검색 폼이 함께 들어 있습니다.

[options="header,autowidth"]
|===
|파라미터 |설명
|`page` |쪽 번호입니다. 1 미만은 1쪽으로 봅니다.
|`tag` |태그 UUID로 글을 필터링합니다. 잘못되었거나 없는 태그는 `404`입니다.
|`category` |옛 태그 필터 주소입니다. `tag`와 같은 응답이며 둘 다 있으면 `tag`를 따릅니다. 북마크가 계속 유효하도록 유지합니다.
|`q` |공개된 글의 제목·요약에서 대소문자를 구분하지 않고 찾습니다. 선택한 태그 하나와 함께 적용합니다.
|===

* 쪽 크기·정렬·표시 항목은 관리자 설정을 따르며 공개 요청으로 바꾸지 않습니다.
* 검색은 공개된 내용만 대상으로 합니다. 비공개·보관 글과 아직 발행하지 않은 가져온 변경은 검색되지 않습니다.
* 쪽 이동 링크는 선택한 태그와 검색어를 유지하고, 태그나 검색어를 바꾸면 1쪽으로 돌아갑니다. 검색어는 앞뒤 공백을 지우며 100자 이하여야 합니다. 더 길면 자르지 않고 검색을 적용하지 않은 채 `400`과 안내를 표시하고 입력한 값을 그대로 남깁니다.
* 결과가 없으면 검색어 지우기와 전체 글 보기 링크를 보여 줍니다.
* 글마다 태그가 여러 개일 수 있어 태그별 글 수의 합은 전체 글 수와 다를 수 있습니다.

== 시리즈

* 시리즈는 순서대로 읽는 글 묶음입니다. 공개된 글이 1개 이상인 시리즈만 보이며, 순번·글 수·이동 대상은 공개된 글만으로 계산합니다. 비공개 글의 제목·개수·순번은 드러나지 않습니다.
* `GET /series`는 시리즈 카드 목록입니다. 대표 이미지는 첫 번째 공개 글의 표지이고 없거나 보관 사본이 없으면 내장 썸네일입니다.
* `GET /series/{seriesId}`는 시리즈 안의 공개 글을 시리즈 순서대로 보여 줍니다. 없는 시리즈, 형식이 잘못된 ID, 공개 글이 하나도 없는 시리즈는 모두 `404`입니다.

== 개별 게시글

* `postId`는 블로그가 저장한 내부 UUID입니다. Notion 페이지 ID나 제목으로 대신 조회할 수 없습니다.
* 공개하지 않은 글과 보관한 글은 `404`입니다.
* 글 화면의 태그는 관리자가 지정한 태그이며 해당 태그의 글 목록으로 이동합니다. Notion 원문 태그는 공개 화면에 표시하지 않습니다.
* 시리즈에 속한 글에는 본문 위에 접을 수 있는 시리즈 목차, 본문 아래에 이전 글·다음 글 링크가 있습니다. 목차는 공개된 글만 순서대로 보여 줍니다.

== 관리 경로

* `/admin/**`은 `BLOG_ADMIN_USERNAME`·`BLOG_ADMIN_PASSWORD`로 설정한 단일 운영자만 쓰며, 둘 중 하나라도 비어 있으면 로그인 화면을 포함해 `403`으로 닫힙니다. 로그인되지 않은 요청은 `/admin/login`으로 이동합니다. 로그인 제출(`POST /admin/login`)과 로그아웃(`POST /admin/logout`)은 보안 필터가 처리하며 이 문서의 예시에 없습니다. 로그인 성공은 `/admin/posts`로 이동하고, 실패는 이유를 구분하지 않고 `/admin/login?error`로 이동합니다. 모든 `POST`는 로그인·로그아웃을 포함해 CSRF 토큰이 필요합니다. 아래 예시는 인증을 통과한 요청에 컨트롤러가 답하는 내용이며 보안 필터는 포함하지 않습니다.
* 관리 응답은 `Cache-Control: no-store`입니다.
* 발행은 발행 확인 화면이 준 `revisionId`와 `generation`을 함께 보냅니다. 그 사이 새 변경이 생기면 발행하지 않고 발행 확인 화면으로 돌아가 안내합니다. 비공개로 전환·보관·보관 해제는 Notion 없이 처리합니다.

=== 글 관리 목록

`status`로 공개(`public`)·비공개(`private`)·보관(`archived`)을 고르며, 없으면 보관한 글을 뺀 모든 글입니다. "전체"는 보관한 글을 포함하지 않으므로 보관한 글은 보관 필터에서 확인합니다. 옛 상태 값(`published`·`changes_pending`·`draft`·`unpublished`)은 같은 묶음으로 읽습니다. `q`는 제목 검색입니다.

* 공개는 발행된 글(가져온 변경이 있어도 포함)이고 비공개는 아직 발행하지 않았거나 비공개로 전환한 글입니다. 저장된 상태 값은 바꾸지 않았습니다.
* 가져온 변경이 있는 공개 글은 `공개` 배지와 `가져온 변경 있음` 배지가 함께 보입니다. 가져오기 실패는 `가져오기 문제` 배지와 설명으로 따로 보이며 공개 상태를 바꾸지 않습니다.

=== 시리즈 관리

시리즈는 제목(1~100자)·짧은 설명(300자 이하)과 순서 있는 글 목록입니다. 글 하나는 시리즈 하나에만 속하며 새로 넣은 글은 마지막에 놓입니다. 시리즈를 삭제하거나 글을 빼도 글·태그·공개 상태는 바뀌지 않습니다.

* `GET /admin/series`는 목록과 생성 폼, `POST /admin/series`는 생성(성공하면 편집 화면으로 이동)입니다.
* `GET /admin/series/{seriesId}`는 편집 화면입니다. 소속 글은 위로·아래로·제외 버튼으로, 후보 글은 추가 버튼으로 바꾸며 저장하기 전에는 서버에 보내지 않습니다. 다른 시리즈에 속한 후보는 현재 시리즈를 함께 보이고 저장하면 이 시리즈로 옮겨집니다.
* `POST /admin/series/{seriesId}`는 제목·설명과 `postId`(최종 소속과 순서)를 한 번에 저장합니다. 없는 글이 있으면 아무것도 저장하지 않고 오류 알림으로 돌아갑니다.
* `POST /admin/series/{seriesId}/delete`는 시리즈만 삭제합니다.

=== 글의 분류 편집

`GET /admin/posts/{postId}/categories`에서 태그(여러 개)·시리즈(0개 또는 1개)·Notion 원문 태그를 한 화면에서 고르고, `POST`로 한 번에 저장합니다. `categoryId`를 여러 번, `seriesId`를 최대 한 번(비우면 해제), `sourceTag`를 여러 번 보냅니다.

* 태그는 보낸 목록 전체로 바꾸며 생략하면 모든 지정을 해제합니다. 시리즈를 바꾸면 새 시리즈의 마지막에 놓입니다.
* 원문 태그는 공개 글이면 공개 중인 내용, 그 밖의 글이면 최신 가져온 내용의 태그가 후보입니다. 고르면 같은 이름의 태그를 재사용하거나 새로 만들어 이 글에 추가로 지정하며, 고르기 전에는 공개 탐색에 나타나지 않습니다. 이후 Notion 가져오기가 지정한 태그와 시리즈를 덮어쓰지 않습니다.
* 저장은 모두 성공하거나 아무것도 바뀌지 않습니다. 본문·발행 상태·Notion 원문은 바뀌지 않으며, 공개 중인 글의 태그와 시리즈는 저장 즉시 반영됩니다.
* 없는 태그·시리즈, 후보가 아니거나 이름 규칙(1~50자)에 맞지 않는 원문 태그는 저장하지 않고 오류 알림으로 돌아갑니다. 폼 값의 UUID 형식이 틀리면 `400`입니다.

=== 발행 확인

`GET /admin/posts/{postId}/review`는 읽기 전용 발행 확인 화면입니다. 제목·표지(없으면 내장 썸네일)·요약, 현재 태그와 시리즈, 가져온 내용 미리보기, 이번에 공개할 가져온 내용의 시각, `Notion에서 수정`·`최신 내용 가져오기`·`분류 편집` 링크를 보여 줍니다.

* 발행 버튼은 확인 화면이 보여 준 `revisionId`와 `generation`만 보냅니다. 그 사이 새 변경이 생기면 발행하지 않고 이 확인 화면으로 돌아와 다시 확인하게 합니다.
* `version=published`는 공개 중인 내용을 비교하는 화면이며 발행 폼 없이 `200`으로 열립니다. 발행할 가져온 내용이 없거나 보관된 글이어도 화면은 열리고 이유만 안내합니다.
* 가져온 내용이 아직 없을 때만 상세 화면으로 `303`으로 돌려보냅니다.
* 확인을 취소하거나 발행에 실패해도 공개 중인 내용과 공개 상태, 앞서 저장한 분류는 바뀌지 않습니다. Notion의 웹 공개 설정은 이 앱의 공개 상태에 영향을 주지 않습니다.
