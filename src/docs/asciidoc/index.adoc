로컬 요청에서는 예시의 `https://blog.example`을 `http://localhost:8080`으로 바꿉니다. 운영 주소는 `https://blog.homelab.robinjoon.xyz`이며 예시 UUID는 테스트 데이터입니다.

== 공개 상태와 응답

* 글은 활성 공개 범위의 구성원이고, 마지막으로 확인한 게시 상태가 공개이며, 읽을 수 있는 저장본이 있을 때만 제공합니다.
* 웹 요청은 저장된 내용만 사용합니다. Notion 장애가 마지막 정상 저장본을 곧바로 숨기지 않습니다.
* 초기 설정과 활성 공개 범위가 없으면 형식이 올바른 게시글 ID에도 먼저 `503`을 반환할 수 있습니다.
* HTML 전체 마크업과 표현 자산은 화면 구현에 따라 바뀔 수 있습니다.

[options="header,autowidth"]
|===
|상태 |의미
|`200 OK` |HTML 또는 RSS를 제공합니다.
|`404 Not Found` |HTML 대상이 범위 밖이거나 미게시 상태입니다. 존재하지 않거나 형식이 잘못된 게시글 ID도 포함합니다.
|`503 Service Unavailable` |아직 초기화되지 않았거나 필요한 저장본·설정을 사용할 수 없습니다.
|===

== RSS 피드

* `GET /feed.xml`은 RSS 2.0 XML을 반환합니다. 현재 공개 범위에서 게시된 글 중 루트·헤더·푸터를 제외한 최근 20개를 요약과 함께 제공합니다.
* `pubDate`는 처음으로 게시 상태를 확인한 시각이며 수정·미게시·재게시로 바뀌지 않습니다.
* 절대 URL은 `blog.public-base-url` 설정에서 만듭니다. 공개할 글이 없어도 준비된 블로그는 빈 피드를 `200`으로 반환합니다.
* 루트 문서가 미게시 상태여도 공개된 자식 글은 피드에 포함될 수 있습니다.
